# Data Model: Regulatory Filing Obligations

## RegulatoryFilingObligation

One persistent record per regulatory filing obligation.

| Field | Type | Persistence | Rules |
|---|---|---|---|
| `id` | UUID string | Stored; generated by the server | Unique, immutable identifier returned to the caller. |
| `dueDate` | ISO-8601 `LocalDate` | Stored | Required valid calendar date supplied by the caller. |
| `ownerEmail` | String | Stored | Required and nonblank. Do not validate email syntax. |
| `effectiveDueDate` | ISO-8601 `LocalDate` | Stored | Calculated at creation by rolling a due date on a weekend or fixed demo holiday forward to the next working day. |

### Derived response fields

These fields are calculated when an obligation is retrieved or included in the due-soon report; they are not persisted.

| Field | Type | Rules |
|---|---|---|
| `deadlineState` | `ON_TRACK`, `AT_RISK`, or `OVERDUE` | `OVERDUE` when `effectiveDueDate` is before the current Amsterdam date; otherwise `AT_RISK` when the effective date is zero through three working days away; otherwise `ON_TRACK`. |
| `escalationState` | `ESCALATED` or `NONE` | `ESCALATED` when deadline state is `AT_RISK` or `OVERDUE`; otherwise `NONE`. |
| `escalationOwner` | String or absent | Set to `ownerEmail` when escalated; not set when escalation state is `NONE`. |

## Working-day calendar

Calendar logic uses Monday through Friday, excluding the fixed demo holidays specified for 2026 and 2027 in the feature specification. A due date rolls forward until it is a working day. Business “today” is obtained from a controllable clock in `Europe/Amsterdam`.

## Due-soon report

An ordered list of obligation response objects whose derived `deadlineState` is `AT_RISK` or `OVERDUE`, sorted by `effectiveDueDate` ascending. `ON_TRACK` records are excluded.

## Validation and errors

- Reject an invalid or missing due date and a blank owner email with HTTP 400 and RFC 9457 Problem Details.
- A nonblank owner email is accepted without format validation.
- Reject lookup of an unknown identifier with HTTP 404 and RFC 9457 Problem Details.
- Date values at API boundaries use ISO-8601.
